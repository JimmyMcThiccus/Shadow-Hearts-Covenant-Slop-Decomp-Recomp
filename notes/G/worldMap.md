# worldMap (JP 0x00506be0 … 0x0050b0b0, 35 methods + worldMapThm/Fade/Light/Point; `worldMap` object 0x92c bytes, CPolObj + DelayDeleteObject)

The overworld "area select" screen (not a walkable map in the demo): a textured world picture with a list of selectable areas ("trial map" table), reached by
`CFieldSocket::WorldMapJump[A](world, sub, ?)` (`new worldMap`, `initialize(world, sub, extra)`, `Entry` into the poller) or the field map name `"WORLDMAP"`.

* Data: `WORLDMAP.PKB` textures — `mReadDataRequest` (JP 0x00507150) reads one of 5 files chosen by `+0x8d8` (world id) via `DvdromOrder::ReadOrder`, callback `DVD_CBFunc` -> `m_TexRead`, `m_pPT` (`primTex`).
* Tables in the overlay: `mWorldMapTbl` (0x555580, 0x30 B), `mTrialMapTbl` (0x554e40, 0x730 B = 23 records of 0x50 bytes `SUBMAP_DATA`: `char name[0x20]` (Shift-JIS) | `char hint[0x20]` | `char map[8]` (field map name, e.g. "AP_00_U") | 8 flag bytes; `mScriptFilter` hides entries by script flags), `mSlotBaseTbl` (0x554450, 0x360 B: 12-byte slot descriptors), `mAREAICONTbl`, `mAREACOLORTbl`, `mAREASLOTCOLORTbl`, `mAREASLOTBASECOLORTbl`, `mAreaBasePoint`, `mStarPos`, `mDemonAttr` (0x554360, 72 B: attribute of each of 72 demons shared with Solomon).
* State machine `+0xd4` (Polling JP 0x005071d0): 0 wait texture read -> 1 wait `MenuObj::IsReadyField` + fade-in -> 2 setup world/menu windows (`mSetupWorldMap`, `mSetupMenuWin`, `mScriptFilter`) -> (6/8 `mNewPointDemo` for newly unlocked areas) -> 9 tutorial window check -> 10 tutorial text (Circle to continue) -> 0x10 `mSetupSelectWin` + menu fade-in -> 0x11 wait fade -> 0x12 selection loop (`mCheckKey`: Circle = decide (0x13 => leave to field), Cross = cancel (area -1 => title), d-pad up/down = `mSearchPrev/Next` + `mSetTextScroll`, returns 0xc to open `CmdMenu` (triangle), 0xb to switch world) -> 0x13 cleanup -> 0x14 jump: `FieldMapJump(sub.map, 1)` after `newGameInit::initializeGameData`, or `opening()` when cancelled from the first screen. 0xc..0xf: menu (CmdMenu page 0 via `worldMap::CMN` callback; menu num 1/2/4 decide continue/return).
* `GetWorldMapInfo()` (main) returns the `"WM"` chunk of `CFieldSaveData`: `{s16 world, s16 sub, u32 extra}` remembered across visits.
* Helper classes: `worldMapThm` (background/scroll sprites, 8 methods), `worldMapFade` (fadeIn/fadeOut/`m_FadeReady`), `worldMapLight`, `worldMapPoint` (area dot sprites), `mNewPointDemo` (unlock animation).
