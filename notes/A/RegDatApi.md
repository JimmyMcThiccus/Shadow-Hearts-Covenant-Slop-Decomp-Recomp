# RegDatApi (JP 0x37b130..0x37d98c; US 0x3b9060..0x3bb940)
Heap in reserved RAM 0x108000..0x200000 (first-fit, 16-B block headers `{tag[4], prev, next, size}`), two blobs loaded at boot: tag "reg1" = `common/sshmes.jpn` (US `.na`; names/descriptions, Shift-JIS fixed width), "reg2" = `common/sshdat.jpn` (records). Blob format: `u32 count; u32 total; {u32 tag; u32 offset} * count` (tag_i at +8+8i, offset_i at +0xc+8i). Table sizes sshdat (33): 0: 340 (12 x 0x1c + 4), 4: 9612 jagged, ... sshmes (44).
`GetRegDat(kind, index, sub)` / `GetRegCnt(kind, sub)`: kinds 0..0x22 = name / description pointers (stride 0x12 or 0x50) resolved through the u16 name index stored in the matching record; 0x23..0x25 = offset tables; 0x26..0x43 = record arrays (strides 0x1c,0x20,0x38,0x10,0x34,0x18,0x2c,0x30,8,0xc,0x44,0x40,0x48 ...), jagged tables (0x2a, 0x2b, 0x2d, 0x36, 0x3f) take `sub>=0`. Kinds 4, 0x16, 0x2c use `BtlSaveSec::ourBtlSaveDat+4` (0..3) to pick tables 6..9. US GetRegDat is 0x14a0 (JP 0x1250): extra kinds. Tables encoded in `regdat.rs` (`DATA_KINDS`, `NAME_KINDS`). Verified: SSHMES entry 0 = "カレン" (Karin).
Main users: BtlSocket (`GetRegDat(0x2f, id, -1)` = monster set table), menus, shops.
